
## Supported features in ansible-oracle

WARNING: Please check the official Compatibility List from Oracle for RDBMS, Oracle Restart and Grid Infrastructure. +
`ansible-oracle` only supports combinations from Oracle with exceptions from the following table.

IMPORTANT: As of `ansible-oracle` 5.0 only Oracle 19c and 26ai are supported for RDBMS.
Installation and tests are done for Single Instance databases without and with Oracle Restart. +
Grid Infrastructure for a Cluster is not tested and will probably not work. +
Older releases (11.2, 12.1, 12.2, 18c, 21c) are rejected by the assert of `db_homes_config`,
see link:guides/breaking_changes.adoc[Breaking Changes - Upgrade Guide].

IMPORTANT: All Editions from Oracle are supported.
See documentation from Oracle for differences between Enterprise and Standard Edition (SE, SE One and SE2)

26ai

NOTE: Terms used in this document: +
*Oracle Restart*: Grid Infrastructure for a Standalone Server (`oracle_install_option_gi: HA_CONFIG`), Single Instance databases with ASM on one host. +
*Grid Infrastructure*: Grid Infrastructure for a Cluster (`oracle_install_option_gi: CRS_CONFIG`). +
*RAC* (Real Application Clusters) and *RAC One Node* need Grid Infrastructure. +
Both Oracle Restart and Grid Infrastructure use the software of Grid Infrastructure (`oracle_home_gi`).
